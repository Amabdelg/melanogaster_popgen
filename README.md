# Drosophila melanogaster Population Genomics

## Project Overview
This project investigates genetic differentiation between geographically separated populations of Drosophila melanogaster using whole-genome sequencing data.

## Research Question
How genetically differentiated are geographically separated populations of Drosophila melanogaster?

## Methods
- ANGSD: Genotype likelihoods and allele frequency analysis
- PCAngsd: Population structure and PCA
- VCFtools: FST analysis
- R: Data visualization

## Project Structure
- data/: Sample metadata
- scripts/: Analysis scripts
- results/: Analysis outputs
- figures/: Visualizations
